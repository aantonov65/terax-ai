# ww-2 Runtime Bundle

This is a curated runtime subset of `ww-2`, generated by `pnpm engine:bundle`.

It includes only the Python entrypoints, imported support modules, LFS/research/strategy prompt assets, format contracts, and Python requirements used by the hosted WWX blackbox runtime.

It intentionally excludes product data, batch outputs, local reports, logs, caches, uploads, broad workflow experiments, and unrelated tools.
