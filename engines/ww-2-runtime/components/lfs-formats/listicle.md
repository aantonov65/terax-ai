FORMAT: LISTICLE
A numbered list where each point dismantles a failed approach and builds toward one conclusion.


LFS V4.1 OUTLINE USE:
This file is the selected native shape for the outline writer. Treat the format as the container, then fill every beat with the source swipe pressure curve, product mechanism, and buyer-facing scene evidence.

The outline must preserve this format's narrator role, emotional engine, beat order, and proof weight. Each beat should name what gets said, what concrete scene or evidence carries it, where the mechanism enters, and where the product earns its first product mention.

Recovery proof, result timelines, victory scenes, and CTA confidence enter after the product or routine discovery has happened. The final script should be planned as feed-native LFS: one thought per paragraph, blank line between thoughts, `========` dividers between sections.

BEAT SEQUENCE:
1. Hook — the list promise. "X things I got wrong about [problem]" or "X reasons [common solutions] keep failing." The number is in the first sentence.
2. Point 1 — the most common failed solution. Name it. Price it. Explain the biological reason it structurally can't work. Each point is its own paragraph.
3. Point 2 — the second most common. Same structure: name, price, why it fails mechanically.
4. Point 3 — the one the narrator believed in longest. More emotional weight. The disappointment is personal.
5. Point 4 (optional) — the expensive professional option. Follow the money — what they charge vs what it costs them.
6. The pattern — step back and name what all the points have in common. One structural limitation they all share. This is where the mechanism enters: the missing piece that explains the ceiling.
7. The mechanism — brief. The listicle already did the dismantling work. The mechanism is the ANSWER to the pattern, not a separate lecture.
8. The search + product — compressed. The narrator finds the one thing that addresses the pattern.
9. The result — one transformation beat per list point reversed. "The [thing from point 1] stopped. The [thing from point 3] changed."
10. CTA — logical tone. The listicle reader is a thinker. Math, comparison, guarantee.

WEIGHT: 50% on beats 2-5 (the list points). Each point must feel like its own mini-revelation. If the points are surface-level ("I tried X, it didn't work"), the format failed. Each point must explain WHY.

WHAT MAKES THIS DIFFERENT: The structure IS the argument. Each point builds cumulative evidence. By the time the mechanism arrives, the reader has already concluded it themselves from the pattern across points. The narrator doesn't need to sell — the list did the selling.
